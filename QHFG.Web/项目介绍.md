# QHFG.Web 项目介绍

> **可再生能源分析与系统优化平台（REASON）** — 前端 Web 应用

---

## 一、项目背景

随着全球碳中和目标的推进，可再生能源（风能、太阳能等）在能源结构中的占比持续提升。准确评估可再生能源资源潜力、分析其时空分布特征、并支撑高比例可再生能源系统的规划与优化，已成为能源与环境领域的重要研究课题。

**QHFG.Web** 是「可再生能源分析与系统优化平台（REASON）」的前端子项目，由清华大学环境学院及相关研究团队建设。平台面向科研人员、政策制定者及行业从业者，提供：

- 多维度可再生能源资源数据的在线查询与可视化
- 基于 GIS 的 2D/3D 地图交互分析
- 区域统计图表与数据导出
- 研究成果与专题内容的展示

后端数据服务部署于 QGIS / 自定义 API 服务器，前端通过 HTTP 接口获取地图图层、统计表格及图例等资源。

## 二、项目概述

| 项目属性 | 说明 |
|---------|------|
| 项目名称 | QHFG.Web（REASON 平台前端） |
| 项目类型 | 单页 Web 应用（SPA） |
| 构建工具 | Vite 5 |
| 前端框架 | Vue 3（Composition API + `<script setup>`） |
| 路由模式 | Hash 路由（`createWebHashHistory`） |
| 后端接口 | `http://129.211.174.149:18080` |
| 开发命令 | `pnpm install` → `pnpm dev` |
| 生产构建 | `pnpm build` |

本项目的核心页面为 **数据服务（DataService）**，用户登录后可按资源类型、数据类型、空间/时间分辨率等条件筛选可再生能源数据，在 OpenLayers 2D 地图或 Cesium 3D 地球上浏览图层，并通过 ECharts 查看区域统计曲线与表格，支持数据下载。

## 三、项目功能

| 功能模块 | 功能描述 |
|---------|---------|
| **首页展示** | 全屏滚动式首页，展示系统标题、三大研究主题入口及联系方式 |
| **用户认证** | 登录、注册（邮箱验证码）、忘记密码；Token 持久化与路由守卫 |
| **多语言切换** | 中文 / 英文国际化（vue-i18n），语言偏好本地存储 |
| **数据筛选** | 树形条件面板：资源类型 → 数据类型 → 空间/时间分辨率，支持条件编辑（管理员） |
| **2D 地图** | 基于 OpenLayers，天地图底图 + WMS 业务图层，支持点选识别、坐标显示 |
| **3D 地图** | 基于 Cesium 三维地球，支持缩放、旋转、点选识别 |
| **2D/3D 切换** | 同一数据集在二维与三维视图间无缝切换 |
| **筛选结果** | 展示已选图层列表、图例预览，支持勾选与清除 |
| **统计图表** | 区域级联选择、时间尺度（年/月/小时）筛选，ECharts 折线/柱状图展示 |
| **数据表格** | 统计表格展示与 Excel 数据下载 |
| **专题文章** | 三大主题（资源潜力、发展路径、系统韧性）下的研究论文/报告页面 |
| **关于我们** | 平台介绍与团队信息 |

## 七、核心业务流程

```
用户登录
   ↓
进入数据服务页（DataService）
   ↓
ConditionBox 选择筛选条件（资源 → 类型 → 分辨率）
   ↓
emit 筛选结果 → DataService 更新 qgsMapPath / tifMapPath
   ↓
Map2D / Map3D 加载 WMS 图层并渲染
   ↓
用户点选地图 → 调用 getPointData 识别数值
   ↓
ChartBox 选择区域与时间 → 调用 getLinedata / getExcelData 展示图表与表格
   ↓
ToolBox 支持数据下载（getDownloadData）
```
