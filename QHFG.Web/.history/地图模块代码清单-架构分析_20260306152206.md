# 地图模块代码清单 - 架构分析

> **项目地图能力类型：** 2D + 3D 并存（可切换，非联动）

---

## 📊 一、项目地图能力判断

### 地图能力类型：**2D + 3D 并存**

**判断依据：**
- ✅ 同时使用 OpenLayers（2D）和 Cesium（3D）
- ✅ 通过 `v-show` 控制显示/隐藏，实现切换
- ✅ 两个地图组件接收相同的 props（`qgsMapPath`、`tifMapPath`）
- ❌ **不是联动**：切换时不会同步相机位置、缩放级别等状态
- ✅ **数据统一**：两个地图使用相同的数据源（WMS服务）

**技术栈：**
- **2D地图引擎**：OpenLayers 10.3.1
- **3D地图引擎**：Cesium 1.99
- **底图服务**：天地图（Tianditu）
- **数据服务**：WMS（Web Map Service）
- **坐标系**：EPSG:4326（地理坐标系）

## 🔍 六、关键技术点总结

### 1. WMS服务Token认证（Map2D.vue）
**问题**：标准WMS协议不支持自定义Header  
**解决方案**：使用 `tileLoadFunction` 自定义加载函数

```javascript
tileLoadFunction: function (imageTile, src) {
  fetch(src, {
    headers: { Token: token }
  })
    .then(response => response.blob())
    .then(blob => {
      imageTile.getImage().src = URL.createObjectURL(blob);
    });
}
```

### 2. 双分辨率策略（Map2D.vue）
**问题**：全球范围数据渲染性能问题  
**解决方案**：低缩放级别用大瓦片，高缩放级别用小瓦片

```javascript
// 低分辨率（大范围）
const createQgjZoomLayer1 = () => {
  const customTileGrid = new TileGrid({
    tileSize: 1024, // 大瓦片
    resolutions: [0.703125, 0.3515625, 0.17578125],
  });
};

// 高分辨率（局部）
const createQgjZoomLayer2 = () => {
  const customTileGrid = new TileGrid({
    tileSize: 256, // 小瓦片
    resolutions: [0.3515625, 0.17578125, 0.087890625],
  });
};
```

### 3. 2D/3D切换机制（DataService.vue）
**实现方式**：使用 `v-show` 控制显示/隐藏

```javascript
const dimensionFlag = ref(2);
const changeMap = () => {
  dimensionFlag.value = dimensionFlag.value === 2 ? 3 : 2;
};

<Map2D v-show="dimensionFlag == 2" :qgsMapPath="qgsMapPath" />
<Map3D v-show="dimensionFlag == 3" :qgsMapPath="qgsMapPath" />
```

### 4. 3D地球自动旋转（Map3D.vue）
**实现方式**：监听时钟事件，每帧旋转相机

```javascript
const startAutoRotate = () => {
  rotateHandler = viewer.clock.onTick.addEventListener(() => {
    viewer.camera.rotateRight(Cesium.Math.toRadians(0.05));
  });
};
```

### 5. 多语言底图切换（Map2D.vue）
**实现方式**：根据语言返回不同的图层数组

```javascript
const getBaseLayersByLocale = (locale) => {
  if (locale === "english") {
    return [tiandiMapLayer, tiandituBoundaryLayer]; // 无中文注记
  } else {
    return [tiandiMapLayer, tiandituBoundaryLayer, tiandituMessageLayer]; // 有中文注记
  }
};
```

## 📝 七、面试重点问题

### Q1: 如何实现2D/3D地图切换？
**答案：**
1. 使用 `v-show` 控制两个地图组件的显示/隐藏
2. 通过 `dimensionFlag` 状态控制切换
3. 两个地图组件接收相同的props（`qgsMapPath`、`tifMapPath`）
4. 切换时通过事件总线通知3D地图开始旋转

### Q2: WMS服务如何实现Token认证？
**答案：**
1. 标准WMS协议不支持自定义Header
2. 使用 `tileLoadFunction` 自定义瓦片加载函数
3. 在fetch请求中添加Token Header
4. 将响应转换为Blob，创建ObjectURL赋值给瓦片图片

### Q3: 如何优化地图性能？
**答案：**
1. **双分辨率策略**：低缩放级别用1024px大瓦片，高缩放级别用256px小瓦片
2. **自定义TileGrid**：优化瓦片网格配置
3. **按需加载**：只加载可视区域内的瓦片
4. **图层管理**：及时移除不需要的图层

### Q4: 2D和3D地图的区别？
**答案：**
1. **引擎不同**：OpenLayers（2D）vs Cesium（3D）
2. **图层加载方式**：TileWMS（2D）vs WebMapServiceImageryProvider（3D）
3. **交互方式**：平面点击（2D）vs 3D场景点击（3D）
4. **功能差异**：2D适合平面展示，3D适合立体可视化

### Q5: 如何实现地图点击查询？
**答案：**
1. **2D地图**：监听 `map.on("click")` 事件，获取坐标，调用 `getPointData` 接口
2. **3D地图**：使用 `ScreenSpaceEventHandler` 监听点击，获取坐标，调用接口
3. 显示弹窗展示查询结果
