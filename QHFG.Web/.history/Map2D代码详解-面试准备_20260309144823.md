# Map2D.vue 代码详解 - 面试准备

## 📋 一、业务作用

### 核心功能
**Map2D组件是一个基于OpenLayers的2D地图可视化组件，主要功能包括：**

1. **地图展示**
   - 展示全球范围的2D平面地图
   - 支持多图层叠加（底图、数据图层、注记图层、边界图层）

2. **数据可视化**
   - 加载WMS服务的数据图层（如风力发电潜力数据）
   - 根据用户选择的条件动态切换数据图层
   - 支持多语言切换（中文/英文）

3. **交互功能**
   - 地图点击查询：点击地图获取该点的数据值
   - 标记点显示：在点击位置显示红色标记点
   - 弹窗展示：显示查询到的数据值和坐标信息
   - 区域高亮：根据图表选择高亮显示行政区域

4. **性能优化**
   - 双分辨率策略：低缩放级别用大瓦片，高缩放级别用小瓦片
   - 按需加载：只加载可视区域内的瓦片
   - 防抖处理：地图移动事件使用防抖优化

## 🗺️ 四、WMS图层怎么加载？

### 核心实现：双分辨率策略

#### 1. **低分辨率图层**（createQgjZoomLayer1）- 大范围

```javascript
const createQgjZoomLayer1 = () => {
  // 自定义瓦片网格
  const customTileGrid = new TileGrid({
    tileSize: 1024,  // 大瓦片（1024px）
    origin: [-180, 90],
    resolutions: [
      0.703125,      // 缩放级别 0
      0.3515625,     // 缩放级别 1
      0.17578125,    // 缩放级别 2
    ],
  });
  
  const token = JSON.parse(localStorage.getItem("leiyangUser"))?.token;
  
  // 创建WMS数据源
  const qgjMapSource = new TileWMS({
    url: `${baseURL}/map/getmap`,
    params: {
      SERVICE: "WMS",
      VERSION: "1.1.0",
      REQUEST: "GetMap",
      Map: props.qgsMapPath,      // QGIS工程文件路径
      LAYERS: props.tifMapPath,   // TIF图层文件名
      FORMAT: "image/png",
      CRS: "EPSG:4326",
      language: locale.value,     // 多语言支持
    },
    tileGrid: customTileGrid,
    serverType: "geoserver",
    
    // ⭐ 关键：自定义瓦片加载函数（实现Token认证）
    tileLoadFunction: function (imageTile, src) {
      fetch(src, {
        headers: {
          Token: `${token}`,  // 添加Token到请求头
        },
      })
        .then((response) => response.blob())
        .then((blob) => {
          const objectUrl = URL.createObjectURL(blob);
          imageTile.getImage().src = objectUrl;
        })
        .catch((err) => {
          console.error("Tile loading error:", err);
        });
    },
  });
  
  return new Tile({
    zindex: 2,
    title: "渲染地图",
    source: qgjMapSource,
    minZoom: 0,
    maxZoom: 12,
  });
};
```

**特点：**
- 使用1024px大瓦片
- 适用于低缩放级别（大范围显示）
- 通过`tileLoadFunction`实现Token认证

### WMS Token认证的创新方案

**问题：** 标准WMS协议不支持自定义Header，无法直接传递Token

**解决方案：** 使用`tileLoadFunction`自定义瓦片加载函数

```javascript
tileLoadFunction: function (imageTile, src) {
  // 1. 使用fetch替代默认的img.src加载
  fetch(src, {
    headers: {
      Token: `${token}`,  // 添加Token到请求头
    },
  })
    .then((response) => response.blob())
    .then((blob) => {
      // 2. 将Blob转换为ObjectURL
      const objectUrl = URL.createObjectURL(blob);
      // 3. 赋值给瓦片图片
      imageTile.getImage().src = objectUrl;
    });
}
```

**优势：**
- ✅ 实现了WMS服务的Token认证
- ✅ 不修改OpenLayers源码
- ✅ 兼容标准WMS协议

## 🖱️ 五、点击查询怎么做？

### 完整流程

```javascript
// 处理点击事件
const handleMapClick = async (event) => {
  // 1. 关闭之前的弹窗
  closePopover();
  
  // 2. 获取点击坐标
  const coordinate = event.coordinate;
  const normalizedCoordinate = normalizeCoordinate(coordinate);
  
  // 3. 添加标记点
  addMarker(normalizedCoordinate);
  
  // 4. 查询数据值
  identifyNum(normalizedCoordinate[0], normalizedCoordinate[1]);
  
  // 5. 计算弹窗位置
  const rawPixel = map.value.getPixelFromCoordinate(coordinate);
  const adjustedPixel = wrapPixel(rawPixel, map.value.getSize()[0]);
  if (adjustedPixel) {
    updatePopoverPosition(adjustedPixel);
    showPopover.value = true;  // 显示弹窗
  }
  
  // 6. 获取区域信息（用于图表联动）
  const params = {
    MAP: props.qgsMapPath,
    LAYERS: props.tifMapPath,
    LONGITUDE: normalizedCoordinate[0],
    LATITUDE: normalizedCoordinate[1],
    language: locale.value,
  };
  let res;
  try {
    res = await request.get("/map/getpoint", { params });
  } catch (e) {
    console.error("[Map2D] getpoint 请求异常:", e);
  }
  
  // 7. 根据缩放级别自动选择区域层级
  if (res && res.data && res.data.area) {
    const area = res.data.area;
    const zoom = map.value.getView().getZoom();
    const result = getLevelByZoom(area, zoom, props.selectMapPath);
    if (result) {
      // 发送区域选择事件，用于图表联动
      bus.emit("mapPointSelected", {
        level: result.level,
        places: result.places,
        map: props.selectMapPath,
        language: locale.value,
        area,
      });
    }
  }
};
```

### 关键步骤详解

#### 1. **坐标标准化**

```javascript
const normalizeCoordinate = (coordinate) => {
  let lon = coordinate[0];
  // 保持经度在[-180, 180)范围内
  lon = (((lon % 360) + 540) % 360) - 180;
  return [
    parseFloat(lon.toFixed(6)),
    parseFloat(coordinate[1].toFixed(6)),
  ];
};
```

**作用：** 处理跨180度经线的情况，确保坐标在有效范围内

#### 2. **添加标记点**

```javascript
const addMarker = (coordinate) => {
  markerSource.clear();  // 清除之前的标记
  rawMarkerCoordinate = coordinate;  // 保存原始坐标
  const normalizeCoord = normalizeCoordinate(coordinate);
  marker = new Feature({
    geometry: new Point(normalizeCoord),
  });
  markerSource.addFeature(marker);
  
  // 发送坐标信息给父组件
  clickedCoordinate2D = {
    longitude: normalizeCoord[0].toFixed(3),
    latitude: normalizeCoord[1].toFixed(3),
  };
  bus.emit("clickedCoordinate2D", clickedCoordinate2D);
};
```

#### 3. **查询数据值**

```javascript
const identifyNum = async (longitude, latitude) => {
  isLoading.value = true;
  identifyNumResult.value = null;
  try {
    const result = await getPointData(
      props.qgsMapPath,
      props.tifMapPath,

  }

```

#### 4. **弹窗位置计算**

```javascript
const updatePopoverPosition = (pixel) => {
  const mapElement = document.getElementById("mapView");
  const mapRect = mapElement.getBoundingClientRect();
  
  // 应用固定像素偏移
  const adjustedPixel = [
    pixel[0] + POPOVER_OFFSET[0],
    pixel[1] + POPOVER_OFFSET[1],
  ];
  
  // 转换为屏幕坐标
  const screenX = adjustedPixel[0] + mapRect.left;
  const screenY = adjustedPixel[1] + mapRect.top;
  
  // 边界处理（确保弹窗在视口内）
  const viewportWidth = window.innerWidth;
  const viewportHeight = window.innerHeight;
  const popoverWidth = 200;
  const popoverHeight = 80;
  const margin = 10;
  
  let finalX = Math.max(
    margin,
    Math.min(screenX, viewportWidth - popoverWidth - margin)
  );
  let finalY = Math.max(
    margin,
    Math.min(screenY, viewportHeight - popoverHeight - margin)
  );
  
  Object.assign(popoverStyle, {
    left: `${finalX}px`,
    top: `${finalY}px`,
    visibility: "visible",
  });
};
```

#### 5. **区域层级自动映射**

```javascript
function getLevelByZoom(area, zoom, selectMapPath) {
  // 按照层级顺序：区域 → 次区域 → 国家 → 电网 → 省级 → 地级 → 县级
  if (zoom >= 8 && area["县级"])
    return { level: "县级", places: [area["县级"]] };
  if (zoom >= 7 && area["地级"])
    return { level: "地级", places: [area["地级"]] };
  if (zoom >= 6 && area["省级"])
    return { level: "省级", places: [area["省级"]] };
  // ... 其他层级
  if (area["区域"])
    return { level: "区域", places: [area["区域"]] };
  return null;
}
```

**作用：** 根据地图缩放级别自动选择合适行政区域层级，用于图表联动

## ⚡ 六、性能优化点

### 1. **双分辨率策略** ⭐⭐⭐⭐⭐

## 📝 八、面试重点问题

### Q1: 为什么使用双分辨率策略？

**答案：**
- **问题**：全球范围数据渲染时，如果统一使用小瓦片，会产生大量请求，影响性能
- **解决方案**：低缩放级别使用1024px大瓦片，减少请求次数；高缩放级别使用256px小瓦片，提供精细展示
- **效果**：既保证了性能，又保证了显示质量

### Q2: 如何实现WMS服务的Token认证？

**答案：**
- **问题**：标准WMS协议不支持自定义Header，无法直接传递Token
- **解决方案**：使用`tileLoadFunction`自定义瓦片加载函数
- **实现**：通过fetch请求添加Token Header，然后将Blob转换为ObjectURL赋值给瓦片图片
- **优势**：既实现了Token认证，又兼容了标准WMS协议

### Q3: 如何处理跨180度经线的情况？

**答案：**
- **问题**：地图可以无限水平滚动，坐标可能超出[-180, 180]范围
- **解决方案**：
  1. 坐标标准化：将经度标准化到[-180, 180)范围内
  2. 多世界副本：计算所有可能的世界副本坐标
  3. 可见性检测：找到距离视图中心最近的可见副本
- **效果**：确保标记点始终可见，提升用户体验

### Q4: 如何优化地图性能？

**答案：**
1. **双分辨率策略**：根据缩放级别使用不同大小的瓦片
2. **防抖处理**：地图移动事件使用防抖，减少计算
3. **按需加载**：只加载可视区域内的瓦片
4. **标记点可见性检测**：只显示可见范围内的标记点
5. **图层管理优化**：复用地图实例，只更新图层
