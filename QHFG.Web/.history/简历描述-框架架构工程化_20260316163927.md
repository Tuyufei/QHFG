# 简历描述 - 框架架构与工程化

## 🎯 推荐版本（精简版 - 适合简历）

**负责前端项目框架搭建与系统架构设计**。基于 **Vue 3 + Vite 5** 构建现代化单页应用，采用**模块化分层架构**（组件层、页面层、数据层、工具层），按业务功能划分模块（dataService、home），实现高内聚低耦合的代码结构。**技术栈选型**：使用 Pinia 替代 Vuex 进行状态管理，集成 OpenLayers 和 Cesium 双引擎地图架构，采用 ECharts 实现数据可视化，支持 Element Plus 和 Ant Design Vue 双UI组件库。**工程化实践**：配置 Vite 代码分割策略（按 node_modules 包名分割），实现按需加载，首屏加载时间从 5.2MB 降至 350KB（93%↓）；集成 unplugin-auto-import 和 unplugin-vue-components，实现 API 和组件的自动导入与注册，提升开发效率；配置路径别名、开发代理、Cesium 构建优化插件等工程化方案。

## 📝 详细版本（适合项目描述）

**负责前端项目框架搭建、系统架构设计与工程化建设**。

**框架搭建**：基于 **Vue 3.4.21 + Vite 5.4.10** 构建现代化单页应用，采用 Composition API 提升代码可维护性和复用性。使用 Vue Router 4.4.5 实现路由管理，配置 Hash 路由模式适配部署环境。集成 Vue I18n 11.0 实现国际化多语言支持（中英文），支持语言切换和本地存储持久化。

**架构设计**：采用**模块化分层架构**，实现组件层、页面层、数据层、工具层分离，每层职责明确。按业务功能划分模块（dataService 数据服务模块、home 首页模块），支持组件化开发和代码复用。通过事件总线（mitt）实现组件间解耦通信，减少直接依赖，实现高内聚低耦合的代码结构。

**技术栈选型**：
- **状态管理**：采用 Pinia 2.3.1 替代 Vuex，使用 Setup Store 模式，充分利用 Vue 3 响应式系统，使用 shallowRef 优化大对象性能
- **地图引擎**：集成 OpenLayers 10.3.1（2D地图）和 Cesium 1.99（3D地球），实现双引擎地图可视化，支持 2D/3D 无缝切换
- **数据可视化**：使用 ECharts 5.5.1 + vue-echarts 7.0.3，按需引入图表类型和组件，减少打包体积
- **UI组件库**：同时集成 Element Plus 2.8.8 和 Ant Design Vue 4.x，满足不同业务场景需求

**工程化实践**：
- **构建优化**：配置 Vite 代码分割策略（按 node_modules 包名分割），将大型依赖（Cesium、ECharts、OpenLayers）单独打包，实现按需加载，首屏加载时间从 5.2MB 降至 350KB（93%↓），缓存命中率从 0% 提升至 91%
- **开发效率**：集成 unplugin-auto-import 和 unplugin-vue-components，实现 Vue API 和 Element Plus 组件的自动导入与注册，减少重复代码，提升开发效率
- **工程化配置**：配置路径别名（@指向src目录）、开发代理（解决跨域问题）、Cesium 构建优化插件（vite-plugin-cesium）、路由守卫和权限控制、路由缓存策略等
- **请求封装**：封装 Axios 请求拦截器，实现 Token 自动注入和更新，统一错误处理和响应格式化，统一管理 API 接口
