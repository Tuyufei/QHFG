## 1. 三级联动树形结构 ⭐⭐⭐⭐⭐

### 1.1 必须理解的三层结构

```
第一层：资源树（Resource Tree）
├── 发电侧
│   ├── 风力发电
│   │   ├── 低空风电
│   │   │   └── 陆上风电 ✅ (叶子节点，可选中)
│   │   └── 高空风电
│   └── 太阳能发电
└── 用电侧

第二层：数据类型树（Data Type Tree）
├── 潜力数据
│   └── 容量因子 ✅ (叶子节点，可选中)
├── 发电潜力
└── 装机潜力

第三层：子节点树（Child Tree）
├── 空间分辨率（2.5MW, 10km）
└── 时间分辨率（年、月、小时）
```

### 1.2 关键代码理解

**选择资源类型时：**
```javascript
const handleResourceCheckChange = (data, checked) => {
  if (checked) {
    // 1. 清空后续所有选择
    selectedDataTypeId.value = null;
    selectedChildId.value = null;
    selectedTimeId.value = null;
    
    // 2. 获取数据类型列表（根据资源ID）
    fetchTypeData(data.id);
    
    // 3. 清空后续数据
    layerListChildData.splice(0, layerListChildData.length);
    layerListTimeData.splice(0, layerListTimeData.length);
  }
};
```

**必须理解的点：**
- ✅ 为什么选择资源类型后要清空后续选择？
- ✅ `fetchTypeData(data.id)` 的作用是什么？
- ✅ 为什么要清空 `layerListChildData` 和 `layerListTimeData`？

**答案：**
- 清空是为了保证数据一致性，避免显示错误的数据类型
- `fetchTypeData` 根据选中的资源ID动态获取对应的数据类型列表
- 清空后续数据是因为资源类型变了，之前的数据类型和子节点不再适用

## 2. 数据获取与更新机制 ⭐⭐⭐⭐

### 2.1 四个关键的数据获取函数

```javascript
// 1. 获取资源类型数据（初始化时调用）
async function fetchResourceData() {
  const language = localStorage.getItem("language");
  const response = await getlayerListResourceData(language);
  const children = response.data?.children ?? [];
  layerListResourceData.splice(0, layerListResourceData.length, ...children);
}

// 2. 获取数据类型数据（选择资源后调用）
async function fetchTypeData(dataId) {
  const data = await getLayerListTypeData(dataId, locale.value);
  layerListTypeData.length = 0;
  layerListTypeData.push(...data);
}

// 3. 获取子节点数据（选择数据类型后调用）
async function fetchChildData(dataId) {
  const response = await getlayerListChildData(dataId, locale.value);
  const children = response.data?.children ?? [];
  layerListChildData.splice(0, layerListChildData.length, ...children);
  
  // 判断是空间分辨率还是时间分辨率
  if (layerListChildData[0].type == "space") {
    showChildTitle.value = 2; // 显示"区域"
  } else {
    showChildTitle.value = 1; // 显示"时间"
  }
}

// 4. 获取时间分辨率数据（选择子节点后调用）
async function fetchTimeData(dataId) {
  const response = await getlayerListChildData(dataId, locale.value);
  const children = response.data?.children ?? [];
  layerListTimeData.splice(0, layerListTimeData.length, ...children);
}
```

### 2.2 必须理解的点

**Q1: 为什么使用 `splice(0, length, ...children)` 而不是直接赋值？**
```javascript
// ❌ 错误方式
layerListResourceData = children; // 会丢失响应式

// ✅ 正确方式
layerListResourceData.splice(0, layerListResourceData.length, ...children);
```
**答案：** `reactive` 创建的响应式对象，直接赋值会丢失响应式。使用 `splice` 可以保持响应式。

**Q2: 为什么 `fetchChildData` 要判断 `type`？**
**答案：** 子节点可能是空间分辨率（如：2.5MW, 10km）或时间分辨率（如：年、月、小时），需要根据类型显示不同的标题。

**Q3: 语言切换时如何保持选中状态？**
```javascript
watch(locale, (newLocale) => {
  fetchResourceData(); // 重新获取资源数据
  if (selectedResourceId.value) {
    fetchTypeData(selectedResourceId.value); // 重新获取数据类型
  }
  if (selectedDataTypeId.value) {
    fetchChildData(selectedDataTypeId.value); // 重新获取子节点
  }
});
```
**答案：** 监听语言变化，如果有选中的节点，重新获取对应语言的数据，保持选中状态不变。

## 3. 路径生成算法 ⭐⭐⭐⭐⭐

### 3.1 递归查找路径算法（核心算法）

```javascript
const getPathByKey = (curKey, layerListData) => {
  let result = []; // 存储最终路径
  
  // 递归函数：深度优先搜索 + 回溯
  let traverse = (curKey, path, layerListData) => {
    if (layerListData.length === 0) {
      return; // 空数组，直接返回
    }
    
    for (let item of layerListData) {
      path.push(item); // 将当前节点加入路径
      
      if (item.id === curKey) {
        // 找到目标节点，保存路径
        result = JSON.parse(JSON.stringify(path));
        return;
      }
      
      // 递归遍历子节点
      const children = Array.isArray(item.children) ? item.children : [];
      traverse(curKey, path, children);
      
      path.pop(); // 回溯：移除当前节点
    }
  };
  
  traverse(curKey, [], layerListData);
  return result;
};
```

### 3.2 算法图解

```
查找节点ID=5的路径：

树结构：
1
├── 2
│   ├── 4
│   └── 5 ✅ (目标节点)
└── 3

执行过程：
1. 遍历节点1，path=[1]
2. 遍历节点2，path=[1,2]
3. 遍历节点4，path=[1,2,4]，不是目标，回溯，path=[1,2]
4. 遍历节点5，path=[1,2,5]，找到目标！保存路径
5. 返回 [1,2,5]
```

### 3.3 必须理解的点

**Q1: 为什么需要回溯（`path.pop()`）？**
**答案：** 因为递归是深度优先搜索，当遍历完一个分支后，需要回到上一层继续遍历其他分支。如果不回溯，路径会包含错误的节点。

**Q2: 为什么使用 `JSON.parse(JSON.stringify(path))`？**
**答案：** 深拷贝路径数组，避免后续回溯操作影响已保存的路径。

**Q3: 如何组合完整路径？**
```javascript
// 获取各层级的路径
pathListResource.value = getPathByKey(selectedResourceId.value, layerListResourceData);
pathListDataType.value = getPathByKey(selectedDataTypeId.value, layerListTypeData);
pathListChild.value = getPathByKey(selectedChildId.value, layerListChildData);
pathListTime.value = getPathByKey(selectedTimeId.value, layerListTimeData);

// 组合完整路径
pathUrl.value =
  pathListResource.value.map((item) => item.name).join("/") +
  "/" +
  pathListDataType.value.map((item) => item.name).join("/") +
  "/" +
  pathListChild.value.map((item) => item.name).join("/") +
  "/" +
  pathListTime.value.map((item) => item.name).join("/");

// 结果：发电侧/风力发电/低空风电/陆上风电/潜力数据/容量因子/2.5MW/10km/年
```

### 4.2 为什么使用多个数组而不是对象数组？

**❌ 对象数组方式：**
```javascript
[
  {
    name: "陆上风电 容量因子(2.5MW,10km,2021)",
    selected: true,
    time: "2021",
    path: "发电侧/.../年",
    unit: "",
    type: "容量因子"
  }
]
```

**✅ 多个数组方式（当前实现）：**
```javascript
{
  filterResultList: ["陆上风电 容量因子(2.5MW,10km,2021)"],
  selectedResults: [true],
  timeResult: ["2021"],
  mapPathUrlList: ["发电侧/.../年"],
  dataUnlitList: [""],
  dataTypeThreeList: ["容量因子"],
}
```

**原因：**
- 通过索引关联，操作更灵活
- 可以批量更新选中状态
- 便于清空和重置

### 4.3 必须理解的点

**Q1: 如何生成显示文本？**
```javascript
// 多年平均
if (timeResult.value == t("conditionBox.annualAverage")) {
  let tempAverageResult = `${资源名称}${数据类型名称}${单位}(${时间})`;
  filterResultList.value.push(tempAverageResult);
} else {
  // 普通时间：为每个时间点生成一个结果
  filterResultList.value = timeResult.value.map((time) => {
    return `${资源名称} ${数据类型名称}${单位}(${参数},${time})`;
  });
}
```

**Q2: 为什么时间结果可能是数组？**
**答案：** 选择"小时"时间粒度时，用户可以选择时间范围（如：2021-01-01 00:00 到 2021-01-01 23:00），需要生成24个时间点，每个时间点对应一个结果。

## 5. 多语言处理 ⭐⭐⭐

### 5.1 显示逻辑

```javascript
// 模板中根据语言显示
<span>{{ locale === "chinese" ? data.name : data.nameEn }}</span>

pathListResource.value[pathListResource.value.length - 1][

```

### 5.2 语言切换时的处理

```javascript
watch(locale, (newLocale) => {
  // 1. 重新获取所有数据（使用新语言）
  fetchResourceData();
  
  // 2. 如果有选中的节点，重新获取对应语言的数据
  if (selectedResourceId.value) {
    fetchTypeData(selectedResourceId.value);
  }
  // ...
});
```

### 5.3 必须理解的点

**Q1: 为什么切换语言要重新获取数据？**
**答案：** 后端返回的数据包含中英文字段（`name` 和 `nameEn`），但树形结构数据需要重新获取才能正确显示。

**Q2: 如何保持选中状态？**
**答案：** 通过 `selectedResourceId.value` 等变量保存选中的节点ID，切换语言后根据ID重新获取数据。

## 6. 时间选择器逻辑 ⭐⭐⭐⭐

### 6.1 四种时间模式

```javascript
// 模式1：年份选择器
if (data.name == t("conditionBox.year")) {
  showTimePicker.value = 1;
  // 显示：<el-date-picker type="years" />
}

// 模式2：年月选择器
else if (data.name == t("conditionBox.month")) {
  showTimePicker.value = 2;
  // 显示：<el-date-picker type="year" /> + <el-date-picker type="months" />
}

// 模式3：时间范围选择器（小时）
else if (data.name == t("conditionBox.hour")) {
  showTimePicker.value = 3;
  // 显示：<el-date-picker type="datetimerange" />
  // 需要生成时间范围内的所有小时点
}

// 模式4：多年平均
else if (data.name == t("conditionBox.annualAverage")) {
  showTimePicker.value = 4;
  timeResult.value = locale.value === "chinese" ? data.name : data.nameEn;
  // 不需要选择器，直接使用节点名称
}
```

### 6.2 小时时间范围处理

```javascript
const handleHourChange = (value) => {
  if (!value || !value[0] || !value[1]) {
    timeResult.value = [];
    return;
  }
  
  const startTime = value[0]; // "2021-01-01 00:00:00"
  const endTime = value[1];   // "2021-01-01 23:00:00"
  
  const result = [];
  const startDate = new Date(startTime);
  const endDate = new Date(endTime);
  
  // 循环生成每个小时的时间点
  const currentDate = new Date(startDate);
  while (currentDate <= endDate) {
    const year = currentDate.getFullYear();
    const month = String(currentDate.getMonth() + 1).padStart(2, "0");
    const day = String(currentDate.getDate()).padStart(2, "0");
    const hour = String(currentDate.getHours()).padStart(2, "0");
    
    result.push(`${year}-${month}-${day} ${hour}:00`);
    
    // 增加一个小时
    currentDate.setHours(currentDate.getHours() + 1);
  }
  
  timeResult.value = result; // ["2021-01-01 00:00", "2021-01-01 01:00", ...]
};
```

### 6.3 必须理解的点

**Q1: 为什么小时时间需要生成数组？**
**答案：** 用户选择时间范围后，需要为范围内的每个小时生成一个数据查询路径，每个小时对应一个结果项。

**Q2: `padStart(2, "0")` 的作用？**
**答案：** 确保月份、日期、小时都是两位数，如 `1` 变成 `01`。

## 7. 组件间数据传递 ⭐⭐⭐⭐

### 7.1 emit 传递数据

```javascript
// 子组件（ConditionBox.vue）
const emit = defineEmits(["updateEmitResultList"]);

const sendConfirm = () => {
  // ... 生成数据
  
  emitResultList.value = [
    [...filterResultList.value],
    [...selectedResults.value],
    [...timeResult.value],
    [...pathUrlList.value],
    [...dataUnitList.value],
    [...dataTypeThreeList.value],
  ];
  
  // 触发事件，传递给父组件
  emit("updateEmitResultList", emitResultList.value);
};
```

```javascript
// 父组件（DataService.vue）
<ConditionBox @updateEmitResultList="updateEmitResultList" />

const updateEmitResultList = (data) => {
  // 接收子组件传递的数据
  emitResultList.value = data;
  
  // 更新结果列表
  for (let i = 0; i < emitResultList.value[0].length; i++) {
    if (!filterResultList.value.includes(emitResultList.value[0][i])) {
      filterResultList.value.push(emitResultList.value[0][i]);
      selectedResults.value.push(emitResultList.value[1][i]);
      // ...
    }
  }
};
```

### 7.2 必须理解的点

**Q1: 为什么使用 `emit` 而不是 `props`？**
**答案：** 数据流向是子组件 → 父组件，`emit` 用于子组件向父组件传递数据，`props` 用于父组件向子组件传递数据。

**Q2: 为什么要检查 `!filterResultList.value.includes(...)`？**
**答案：** 防止重复添加相同的结果项，如果已存在则提示错误。

## 🎯 面试重点问题

### Q1: 如何实现三级联动？
**答案：**
1. 使用三个独立的树形组件
2. 选择第一层时，清空后续选择，调用接口获取第二层数据
3. 选择第二层时，清空后续选择，调用接口获取第三层数据
4. 通过 `check-strictly` 实现父子节点独立选择

### Q2: 路径生成算法的时间复杂度？
**答案：** O(n)，n为树中节点总数。使用深度优先搜索遍历所有节点。

### Q3: 为什么使用多个数组而不是对象数组？
**答案：**
- 通过索引关联，操作更灵活
- 可以批量更新选中状态
- 便于清空和重置

### Q4: 语言切换时如何保持选中状态？
**答案：**
1. 监听 `locale` 变化
2. 重新获取对应语言的数据
3. 根据保存的节点ID重新获取相关数据

### Q5: 如何处理时间范围选择？
**答案：**
1. 用户选择开始时间和结束时间
2. 循环生成时间范围内的所有时间点
3. 为每个时间点生成一个结果项
