## 🔧 二、详细步骤解析

### 步骤1：导入OpenLayers库

```javascript
// Map2D.vue 第38-45行
import Map from "ol/Map.js";                    // 地图类
import View from "ol/View.js";                 // 视图类
import Tile from "ol/layer/Tile";               // 瓦片图层类
import { Vector as VectorLayer } from "ol/layer"; // 矢量图层类
import XYZ from "ol/source/XYZ";                // XYZ瓦片数据源
import { TileWMS } from "ol/source";           // WMS瓦片数据源
import { Vector as VectorSource } from "ol/source"; // 矢量数据源
import TileGrid from "ol/tilegrid/TileGrid";    // 瓦片网格
```

**关键点：**
- OpenLayers采用模块化设计，按需导入
- `Map`：地图容器类
- `View`：地图视图类（控制中心点、缩放级别、投影等）
- `Layer`：图层类（Tile图层、Vector图层等）
- `Source`：数据源类（XYZ、TileWMS、VectorSource等）

---

### 步骤2：创建数据源（Source）

数据源是图层的底层数据提供者，不同的数据源对应不同的数据格式。

#### 2.1 创建XYZ瓦片数据源（天地图底图）

```javascript
// Map2D.vue 第60-62行
const tiandituMapSource = new XYZ({
  url: "http://t0.tianditu.com/DataServer?T=vec_w&tk=xxx&x={x}&y={y}&l={z}",
});
```

**参数说明：**
- `url`：瓦片服务URL模板
- `{x}`、`{y}`、`{z}`：OpenLayers会自动替换为瓦片的行列号和缩放级别

#### 2.2 创建WMS瓦片数据源（数据图层）

```javascript
// Map2D.vue 第86-122行
const qgjMapSource = new TileWMS({
  url: `${baseURL}/map/getmap`,
  params: {
    SERVICE: "WMS",
    VERSION: "1.1.0",
    REQUEST: "GetMap",
    Map: props.qgsMapPath,      // QGIS工程文件路径
    LAYERS: props.tifMapPath,   // 图层名称
    FORMAT: "image/png",
    CRS: "EPSG:4326",
    language: locale.value,
  },
  tileGrid: customTileGrid,     // 自定义瓦片网格
  serverType: "geoserver",
  
  // ⭐ 自定义瓦片加载函数（实现Token认证）
  tileLoadFunction: function (imageTile, src) {
    fetch(src, {
      headers: { Token: `${token}` },
    })
      .then((response) => response.blob())
      .then((blob) => {
        imageTile.getImage().src = URL.createObjectURL(blob);
      });
  },
});
```

**关键点：**
- `TileWMS`：用于加载WMS服务的瓦片数据
- `params`：WMS请求参数
- `tileGrid`：自定义瓦片网格（控制瓦片大小和分辨率）
- `tileLoadFunction`：自定义加载函数（可以实现Token认证等）

#### 2.3 创建矢量数据源（标记点）

```javascript
// Map2D.vue 第225行
const markerSource = new VectorSource();
```

**特点：**
- `VectorSource`：用于存储矢量要素（点、线、面）
- 可以动态添加/删除要素
- 适合标记点、绘制图形等

---

### 步骤3：创建图层（Layer）

图层是数据源和地图之间的桥梁，一个图层对应一个数据源。

#### 3.1 创建瓦片图层（Tile Layer）

```javascript
// Map2D.vue 第63-67行
const tiandiMapLayer = new Tile({
  zindex: 1,           // 图层层级（数字越大越在上层）
  title: "矢量底图",
  source: tiandituMapSource,  // 关联数据源
});
```

**参数说明：**
- `zindex`：图层层级，控制图层的显示顺序
- `source`：关联的数据源
- `minZoom` / `maxZoom`：图层显示的最小/最大缩放级别

#### 3.2 创建矢量图层（Vector Layer）

```javascript
// Map2D.vue 第226-235行
const markerLayer = new VectorLayer({
  zindex: 5,
  source: markerSource,  // 关联矢量数据源
  style: new Style({
    image: new Circle({
      radius: 6,
      fill: new Fill({ color: "red" }),
      stroke: new Stroke({ color: "white", width: 2 }),
    }),
  }),
});
```

**参数说明：**
- `source`：关联的矢量数据源
- `style`：图层样式（点、线、面的样式）

---

### 步骤4：创建地图实例（Map）

地图实例是OpenLayers的核心，所有图层都添加到地图实例中。

```javascript
// Map2D.vue 第683-693行
onMounted(() => {
  map.value = new Map({
    target: "mapView",    // DOM容器ID（必须是已存在的元素）
    layers: getBaseLayersByLocale(locale.value),  // 初始图层数组
    view: new View({
      center: [116.46, 39.92],  // 初始中心点（经纬度）
      projection: "EPSG:4326",  // 投影坐标系
      zoom: 1,  // 初始缩放级别
    }),
    controls: [],  // 不显示默认控件（如缩放按钮、比例尺等）
  });
});
```

**参数说明：**
- `target`：DOM容器ID或DOM元素对象
- `layers`：图层数组（按顺序叠加）
- `view`：地图视图配置
- `controls`：控件数组（如缩放按钮、比例尺等）

**关键点：**
- 必须在`onMounted`中创建，确保DOM元素已存在
- `target`指定的元素必须有宽高（CSS设置）

---

### 步骤5：设置视图（View）

视图控制地图的显示状态（中心点、缩放级别、投影等）。

```javascript
// Map2D.vue 第687-691行
view: new View({
  center: [116.46, 39.92],  // 初始中心点 [经度, 纬度]
  projection: "EPSG:4326",  // 投影坐标系（地理坐标系）
  zoom: 1,  // 初始缩放级别（数字越大越放大）
})
```

**参数说明：**
- `center`：地图中心点坐标 `[经度, 纬度]`
- `projection`：投影坐标系
  - `EPSG:4326`：地理坐标系（经纬度）
  - `EPSG:3857`：Web墨卡托投影（常用）
- `zoom`：缩放级别
  - 0：全球视图
  - 1-5：大范围视图
  - 6-10：中等范围视图
  - 11+：局部详细视图

**动态修改视图：**
```javascript
// 修改中心点
map.value.getView().setCenter([120, 30]);

// 修改缩放级别
map.value.getView().setZoom(5);

// 同时修改中心点和缩放级别
map.value.getView().setCenter([120, 30]);
map.value.getView().setZoom(5);
```

### 步骤6：添加图层到地图

图层可以在地图创建时添加，也可以动态添加。

#### 6.1 创建时添加图层

```javascript
// Map2D.vue 第684-693行
map.value = new Map({
  target: "mapView",
  layers: [
    tiandiMapLayer,        // 底图（最底层）
    tiandituMessageLayer,  // 中文注记
    tiandituBoundaryLayer, // 境界
    markerLayer,           // 标记点
  ],
  view: new View({ ... }),
});
```

#### 6.2 动态添加图层

```javascript
// Map2D.vue 第656-680行
watch(
  () => [props.qgsMapPath, props.tifMapPath],
  ([newQgs, newTif]) => {
    if (map.value && newQgs && newTif) {
      // 1. 创建新的WMS图层
      qgjZoomLayer1.value = createQgjZoomLayer1();
      
      // 2. 获取基础图层
      const layers = getBaseLayersByLocale(locale.value);
      
      // 3. 插入WMS图层和高亮图层
      layers.splice(1, 0, qgjZoomLayer1.value);  // 在索引1处插入
      layers.push(highLightLayer);  // 添加到末尾
      
      // 4. 设置图层（替换所有图层）
      map.value.setLayers(layers);
    }
  }
);
```

**图层顺序：**
- 数组前面的图层在底层
- 数组后面的图层在上层
- `zindex`属性也可以控制层级，但通常用数组顺序更直观

**常用方法：**
```javascript
// 添加图层
map.value.addLayer(layer);

// 移除图层
map.value.removeLayer(layer);

// 设置所有图层
map.value.setLayers([layer1, layer2, layer3]);

// 获取所有图层
const layers = map.value.getLayers();
```

### 步骤7：绑定事件监听

OpenLayers支持多种事件，如点击、移动、缩放等。

#### 7.1 地图点击事件

```javascript
// Map2D.vue 第470-513行
const handleMapClick = async (event) => {
  const coordinate = event.coordinate;  // 获取点击坐标
  const normalizedCoordinate = normalizeCoordinate(coordinate);
  addMarker(normalizedCoordinate);  // 添加标记点
  identifyNum(normalizedCoordinate[0], normalizedCoordinate[1]);  // 查询数据
  // ...
};

// 绑定事件
map.value.on("click", handleMapClick);
```

**事件对象：**
- `event.coordinate`：点击的坐标 `[经度, 纬度]`
- `event.pixel`：点击的像素坐标 `[x, y]`
- `event.originalEvent`：原始DOM事件

#### 7.2 地图移动事件

```javascript
// Map2D.vue 第544-583行
const handleViewChange = _.debounce(() => {
  // 处理标记点可见性和弹窗位置
  const view = map.value.getView();
  const extent = view.calculateExtent(mapSize);
  // ...
}, 100);

// 绑定事件
map.value.on("moveend", handleViewChange);
```

**常用事件：**
- `click`：点击事件
- `moveend`：移动结束事件
- `move`：移动中事件（频繁触发）
- `zoom`：缩放事件
- `pointermove`：鼠标移动事件

#### 7.3 移除事件监听

```javascript
// Map2D.vue 第738-742行
onBeforeUnmount(() => {
  if (map.value) {
    map.value.un("click", handleMapClick);
    map.value.un("moveend", handleViewChange);
  }
});
```

**关键点：**
- 组件卸载时必须移除事件监听，避免内存泄漏
- 使用`un`方法移除事件监听

## 📊 三、完整示例代码

### 最简单的OpenLayers地图

```javascript
import Map from "ol/Map";
import View from "ol/View";
import Tile from "ol/layer/Tile";
import XYZ from "ol/source/XYZ";

// 1. 创建数据源
const source = new XYZ({
  url: "https://tile.openstreetmap.org/{z}/{x}/{y}.png",

// 2. 创建图层
const layer = new Tile({
  source: source,
});

// 3. 创建地图
const map = new Map({
  target: "map",  // DOM容器ID

    center: [116.46, 39.92],  // 中心点
    zoom: 10,  // 缩放级别
  }),
```

## 🔍 五、关键概念理解

### 1. Source（数据源）vs Layer（图层）

- **Source**：数据的提供者，负责获取数据
- **Layer**：数据的展示者，负责渲染数据

**关系：**
```
Source → Layer → Map
数据源 → 图层 → 地图
```

### 2. 图层叠加顺序

```javascript
layers: [
  tiandiMapLayer,        // 最底层（zindex: 1）
  qgjZoomLayer1,         // 数据图层（zindex: 2）
  tiandituBoundaryLayer, // 境界（zindex: 3）
  markerLayer,           // 标记点（zindex: 5）
  countryPointLayer,     // 最上层（zindex: 10）
]
```

**规则：**
- 数组顺序：前面的在底层，后面的在上层
- zindex属性：数字越大越在上层
- 两者冲突时，以数组顺序为准

### 3. 坐标系统

- **EPSG:4326**：地理坐标系（经纬度）
  - 经度范围：-180 到 180
  - 纬度范围：-90 到 90
  - 单位：度

- **EPSG:3857**：Web墨卡托投影
  - 单位：米
  - 适合Web地图显示

## 📝 六、面试重点问题

### Q1: OpenLayers绘制地图的基本流程是什么？

**答案：**
1. **导入库**：导入Map、View、Layer、Source等类
2. **创建数据源**：创建XYZ、TileWMS、VectorSource等数据源
3. **创建图层**：创建Tile、VectorLayer等图层，关联数据源
4. **创建地图实例**：创建Map对象，指定target、layers、view
5. **设置视图**：配置View的中心点、缩放级别、投影
6. **添加图层**：将图层添加到地图
7. **绑定事件**：绑定click、moveend等事件

### Q2: Source和Layer的区别是什么？

**答案：**
- **Source（数据源）**：负责获取数据，如XYZ、TileWMS、VectorSource
- **Layer（图层）**：负责渲染数据，如Tile、VectorLayer
- **关系**：一个Layer对应一个Source，Layer负责将Source的数据渲染到地图上

### Q3: 如何动态添加图层？

**答案：**
```javascript
// 方法1：添加单个图层
map.addLayer(newLayer);

// 方法2：替换所有图层
map.setLayers([layer1, layer2, layer3]);

// 方法3：获取图层数组，修改后重新设置
const layers = map.getLayers().getArray();
layers.push(newLayer);
map.setLayers(layers);
```

### Q4: 如何实现WMS服务的Token认证？

**答案：**
使用`tileLoadFunction`自定义瓦片加载函数：
```javascript
const source = new TileWMS({
  url: "...",
  params: { ... },
  tileLoadFunction: function (imageTile, src) {
    fetch(src, {
      headers: { Token: token },
    })
      .then(response => response.blob())
      .then(blob => {
        imageTile.getImage().src = URL.createObjectURL(blob);
      });
  },
});
```

### 关键理解

- **Source → Layer → Map**：数据源 → 图层 → 地图
- **图层顺序**：数组顺序决定叠加顺序
- **事件管理**：组件卸载时必须移除事件监听
