## 📦 代码分割策略

### 1. **配置代码**

```javascript
// vite.config.js
build: {
  chunkSizeWarningLimit: 1500,  // 允许单个chunk最大1500KB
  rollupOptions: {
    output: {
      manualChunks(id) {
        // 如果文件路径包含 node_modules
        if (id.includes('node_modules')) {
          // 提取包名，按包名分割
          return id.toString().split('node_modules/')[1].split('/')[0].toString();
        }
      }
    }
  }
}
```

### 2. **工作原理详解**

#### 示例：文件路径解析

```javascript
// 假设有以下依赖文件：
// node_modules/vue/dist/vue.runtime.esm-bundler.js
// node_modules/element-plus/dist/index.esm.js
// node_modules/cesium/Source/Cesium.js
// node_modules/ol/layer/Tile.js

// manualChunks函数处理过程：

// 1. 处理 vue 文件
id = "node_modules/vue/dist/vue.runtime.esm-bundler.js"
id.includes('node_modules')  // true
id.split('node_modules/')[1]  // "vue/dist/vue.runtime.esm-bundler.js"
.split('/')[0]  // "vue"
return "vue"  // 所有vue相关文件打包到 vue.js

// 2. 处理 element-plus 文件
id = "node_modules/element-plus/dist/index.esm.js"
id.split('node_modules/')[1]  // "element-plus/dist/index.esm.js"
.split('/')[0]  // "element-plus"
return "element-plus"  // 所有element-plus相关文件打包到 element-plus.js

// 3. 处理 cesium 文件
id = "node_modules/cesium/Source/Cesium.js"
id.split('node_modules/')[1]  // "cesium/Source/Cesium.js"
.split('/')[0]  // "cesium"
return "cesium"  // 所有cesium相关文件打包到 cesium.js

// 4. 处理 ol 文件
id = "node_modules/ol/layer/Tile.js"
id.split('node_modules/')[1]  // "ol/layer/Tile.js"
.split('/')[0]  // "ol"
return "ol"  // 所有ol相关文件打包到 ol.js
```

### 3. **打包结果**

#### 不使用代码分割（默认）
```
dist/
├── index.html
└── assets/
    └── index-abc123.js  (5MB)  ← 所有代码打包在一起
```

**问题**：
- ❌ 首屏加载慢：需要下载5MB才能看到页面
- ❌ 缓存效率低：修改一行代码，整个文件hash变化，用户需要重新下载5MB
- ❌ 并行加载差：只能单线程下载一个大文件

#### 使用代码分割后
```
dist/
├── index.html
└── assets/
    ├── index-abc123.js      (200KB)  ← 业务代码
    ├── vue-def456.js         (150KB)  ← Vue框架代码
    ├── element-plus-ghi789.js (800KB) ← Element Plus组件库
    ├── cesium-jkl012.js      (2MB)   ← Cesium 3D地图引擎
    ├── ol-mno345.js          (500KB) ← OpenLayers 2D地图引擎
    ├── echarts-pqr678.js     (600KB) ← ECharts图表库
    └── lodash-stu901.js      (70KB)  ← Lodash工具库
```

**优势**：
- ✅ **首屏加载快**：只需要下载200KB业务代码 + 150KB Vue = 350KB
- ✅ **缓存效率高**：修改业务代码，只有index.js的hash变化，其他库文件不变
- ✅ **并行加载**：浏览器可以同时下载多个文件
- ✅ **按需加载**：用户访问地图页面时才加载cesium.js和ol.js

## 🧩 组件自动注册（unplugin-vue-components）

### 1. **配置代码**

```javascript
// vite.config.js
import Components from "unplugin-vue-components/vite";
import { ElementPlusResolver } from "unplugin-vue-components/resolvers";

plugins: [
  Components({
    resolvers: [ElementPlusResolver()],
  }),
]
```

### 2. **Element Plus组件自动注册**

#### 配置前（需要手动导入和注册）

```vue
<!-- DataService.vue - 配置前 -->
<template>
  <div>
    <!-- ❌ 需要先导入组件才能使用 -->
    <el-button type="primary" @click="clearResult">
      {{ $t("message.clear") }}
    </el-button>
    <el-checkbox v-model="selectedResults[index]">
      选项
    </el-checkbox>
  </div>
</template>

<script setup>
// ❌ 需要手动导入组件
import { ElButton, ElCheckbox } from "element-plus";
// 或者全局注册（main.js中）
// import ElementPlus from "element-plus";
// app.use(ElementPlus);  // 会导入所有组件，体积大
</script>
```

#### 配置后（自动注册，按需引入）

```vue
<!-- DataService.vue - 配置后 -->
<template>
  <div>
    <!-- ✅ 直接使用，自动按需引入 -->
    <el-button type="primary" @click="clearResult">
      {{ $t("message.clear") }}
    </el-button>
    <el-checkbox v-model="selectedResults[index]">
      选项
    </el-checkbox>
  </div>
</template>

<script setup>
// ✅ 不需要导入，直接使用！
// 插件会自动检测模板中使用的组件，按需引入
</script>
```

### 3. **自动检测和引入机制**

#### 工作流程

```
1. 构建时扫描所有.vue文件
   ↓
2. 检测模板中使用的组件（如 <el-button>）
   ↓
3. 自动从 element-plus 导入对应组件
   import ElButton from 'element-plus/es/components/button/index.js'
   ↓
4. 自动注册组件
   components: { ElButton }
   ↓
5. 生成类型声明文件（components.d.ts）
```

### 4. **生成的类型声明文件**

```typescript
// components.d.ts (自动生成)
declare module 'vue' {
  export interface GlobalComponents {
    // Element Plus 组件自动注册
    ElButton: typeof import('element-plus/es')['ElButton']
    ElCheckbox: typeof import('element-plus/es')['ElCheckbox']
    ElSelect: typeof import('element-plus/es')['ElSelect']
    ElDatePicker: typeof import('element-plus/es')['ElDatePicker']
    ElTable: typeof import('element-plus/es')['ElTable']
    ElTree: typeof import('element-plus/es')['ElTree']
    
    // 项目组件自动注册
    Map2D: typeof import('./src/components/dataService/Map2D.vue')['default']
    Map3D: typeof import('./src/components/dataService/Map3D.vue')['default']
    ChartBox: typeof import('./src/components/dataService/chart/ChartBox.vue')['default']
  }
}
```

### 5. **按需引入效果**

#### 全局注册（不推荐）


## 📁 路径别名配置

### 1. **配置代码**

```javascript
// vite.config.js
import { fileURLToPath, URL } from "node:url";

resolve: {
  alias: {
    "@": fileURLToPath(new URL("./src", import.meta.url)),
  },
}

// jsconfig.json
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

### 2. **使用对比**

#### 配置前（相对路径）

```vue
<!-- Map2D.vue - 配置前 -->
<script setup>
// ❌ 使用相对路径，难以维护
import bus from "../../../utils/bus";
import { getPointData } from "../../../request/index";
import { useI18n } from "vue-i18n";

// 如果文件移动位置，路径就会出错
// 例如：从 components/dataService/Map2D.vue 
//      移动到 components/map/Map2D.vue
// 所有导入路径都需要修改
</script>
```

#### 配置后（路径别名）

```vue
<!-- Map2D.vue - 配置后 -->
<script setup>
// ✅ 使用路径别名，清晰易维护
import bus from "@/utils/bus";
import { getPointData } from "@/request/index";
import { useI18n } from "vue-i18n";

// 无论文件在哪里，路径都不变
// @ 始终指向 src 目录
</script>
```

### 3. **路径解析示例**

```javascript

// 3. 进入 utils/bus：项目根目录/utils/bus

// 1. @ 指向：src/
// 2. 拼接路径：src/utils/bus
// 3. 最终：src/utils/bus.js ✅
```

### 2. **Cesium的特殊性**

#### Cesium的问题

```javascript
// Cesium 是一个大型3D地图库，包含：
// - 大量静态资源（Workers、Assets、ThirdParty）
// - 特殊的资源路径引用
// - Web Workers 文件
// - 需要特殊的构建配置

// 不使用插件时的问题：
// ❌ 资源路径错误：Cesium的Workers路径找不到
// ❌ 静态资源丢失：Assets文件夹没有正确复制
// ❌ Web Workers无法加载：Worker文件路径错误
// ❌ 构建失败：Vite无法正确处理Cesium的特殊结构
```

#### Cesium目录结构

```
node_modules/cesium/
├── Source/              # 源代码
│   ├── Cesium.js        # 主文件
│   ├── Workers/          # Web Workers
│   │   ├── createVerticesFromGoogleEarthEnterprise.js
│   │   └── ...
│   └── ThirdParty/      # 第三方库
├── Build/               # 构建产物
│   └── Cesium/          # 编译后的文件
└── Assets/              # 静态资源
    ├── Images/          # 图片资源
    └── ...
```

### 3. **插件的作用**

#### 自动处理内容

```javascript
// vite-plugin-cesium 自动处理：

// 1. 资源路径修正
// 将 Cesium 的资源路径从相对路径转换为正确的URL
// 例如：Workers/createVerticesFromGoogleEarthEnterprise.js
//      → /node_modules/.vite/cesium/Workers/createVerticesFromGoogleEarthEnterprise.js

// 2. 静态资源复制
// 自动将 Assets 文件夹复制到构建输出目录
// dist/assets/cesium/Assets/...

// 3. Web Workers 支持
// 配置 Worker 文件的正确路径和加载方式

// 4. 构建优化
// 优化 Cesium 的打包体积和加载性能
```
