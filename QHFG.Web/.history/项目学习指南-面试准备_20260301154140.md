### 1.3 核心技术选型原因

**为什么选择 Vue 3？**
- Composition API 提供更好的逻辑复用和代码组织
- 更好的 TypeScript 支持（虽然项目未使用TS）
- 性能优化（响应式系统重构）

**为什么同时使用 OpenLayers 和 Cesium？**
- OpenLayers：轻量级，适合2D平面地图展示
- Cesium：强大的3D地球渲染能力，支持地形、影像叠加
- 两者互补，满足不同场景需求

**为什么使用 mitt 而不是 Pinia？**
- 组件间通信更灵活，解耦性强
- 适合跨组件的事件通知（如地图点击、数据更新）
- Pinia 主要用于全局状态，mitt 用于事件流

## 2. 核心功能模块详解

### 2.1 用户认证系统

#### 2.1.1 登录流程

**关键代码位置：** `src/views/Login.vue`, `src/request/index.js`

**流程：**
1. 用户输入用户名密码
2. 调用 `loginInterface(username, password)`
3. 后端返回 token 和用户信息
4. 存储到 `localStorage.setItem("leiyangUser", JSON.stringify({username, token}))`
5. 触发全局事件 `window.dispatchEvent(new Event("loginStatusChanged"))`
6. 跳转到首页

**Token 管理：**
- 存储在 localStorage
- 通过 Axios 请求拦截器自动添加到请求头
- 响应拦截器支持 token 自动刷新

#### 2.1.2 登录组件核心代码详解

**文件：** `src/views/Login.vue`

##### 1. 表单数据绑定

```javascript
// 第57-60行：创建响应式表单数据
const form = reactive({
  username: "",  // 用户名，初始值为空
  password: "",  // 密码，初始值为空
});
```

**解释：**
- `reactive()`：Vue 3 Composition API，创建响应式对象
- 当 `form.username` 或 `form.password` 改变时，视图自动更新
- 与模板中的 `v-model="form.username"` 实现双向绑定

##### 2. 登录函数核心逻辑

```javascript
// 第62-91行：登录函数
const login = async () => {
  // 1. 解构赋值，获取用户名和密码
  const { username, password } = form;
  
  // 2. 表单验证：检查用户名和密码是否为空
  if (!username || !password) {
    ElMessage.warning(t("login.userNameAndPasswordRequired"));
    return;  // 验证失败，提前返回
  }

  try {
    // 3. 调用登录接口（异步操作）
    const res = await loginInterface(username, password);
    
    // 4. 判断响应状态码
    if (res.code === 200) {
      // 5. 登录成功：存储用户信息和 token
      localStorage.setItem(
        "leiyangUser",
        JSON.stringify({
          username: username,
          token: res.data.token,  // 从响应中获取 token
        })
      );
      
      // 6. 触发全局事件，通知其他组件登录状态改变
      window.dispatchEvent(new Event("loginStatusChanged"));
      
      // 7. 显示成功消息
      ElMessage.success(t("login.loginSuccess"));
      
      // 8. 跳转到首页
      router.push("/home");
      
      // 9. 保存当前菜单状态
      localStorage.setItem("currentSystemMenu", "home");
    } else {
      // 10. 登录失败：显示错误消息
      ElMessage.error(res.message || t("login.loginFailed"));
    }
  } catch (err) {
    // 11. 异常处理：网络错误、超时等
    ElMessage.error(t("login.unauthorized"));
  }
};
```

**逐行解释：**

**第63行：解构赋值**
```javascript
const { username, password } = form;
```
- 从 `form` 对象中提取 `username` 和 `password`
- 等价于：`const username = form.username; const password = form.password;`

**第64-68行：表单验证**
```javascript
if (!username || !password) {
  ElMessage.warning(t("login.userNameAndPasswordRequired"));
  return;
}
```
- `!username || !password`：逻辑或，如果任一为空则条件为真
- `ElMessage.warning()`：Element Plus 警告消息提示
- `return`：提前返回，不执行后续代码

**第71行：异步接口调用**
```javascript
const res = await loginInterface(username, password);
```
- `async/await`：异步编程，等待接口返回结果
- `loginInterface`：从 `@/request/index.js` 导入的 API 函数
- `await`：暂停函数执行，直到 Promise 完成

**第73-80行：存储用户信息**
```javascript
localStorage.setItem(
  "leiyangUser",
  JSON.stringify({
    username: username,
    token: res.data.token,
  })
);
```
- `localStorage.setItem()`：浏览器本地存储，数据持久化
- `JSON.stringify()`：对象序列化为 JSON 字符串（localStorage 只能存字符串）
- 存储结构：`{"username": "user123", "token": "eyJhbGci..."}`

**第81行：触发全局事件**
```javascript
window.dispatchEvent(new Event("loginStatusChanged"));
```
- `window.dispatchEvent()`：触发自定义事件
- 作用：通知 `HomeView.vue` 更新登录状态显示
- 解耦组件，不需要直接调用其他组件

**第83行：路由跳转**
```javascript

```
- `router.push()`：Vue Router 编程式导航
- 跳转到 `/home` 路由，会触发路由守卫

**知识点：**
- **async/await**：异步编程模式
- **try/catch**：错误处理机制
- **localStorage**：浏览器本地存储
- **JSON.stringify()**：对象序列化
- **事件系统**：组件间通信

#### 2.1.3 Axios 请求拦截器（Token 自动添加）

**文件：** `src/request/axios.js`

```javascript
// 第13-48行：请求拦截器
request.interceptors.request.use(
  (config) => {
    // 1. 从 localStorage 获取用户信息
    const userInfo = localStorage.getItem("leiyangUser");
    let token = "";
    
    // 2. 解析用户信息，提取 token
    if (userInfo) {
      try {
        const user = JSON.parse(userInfo);  // 字符串转对象
        token = user.token;  // 获取 token
      } catch (e) {
        console.error("解析用户信息失败:", e);
      }
    }

    // 3. 设置请求头，添加 token
    config.headers = {
      ...config.headers,  // 保留原有请求头
      "Content-Type": "application/json;charset=UTF-8",
      token: token,  // 添加 token 到请求头
    };

    // 4. 处理 GET 请求参数
    if (config.method === "get") {
      config.params = {
        ...config.params,
      };
    }
    
    return config;  // 返回配置对象
  },
  (error) => {
    return Promise.reject(error);  // 请求错误时拒绝
  }
);
```

**逐行解释：**

**第16行：获取用户信息**
```javascript
const userInfo = localStorage.getItem("leiyangUser");
```
- 从 localStorage 读取存储的用户信息（JSON 字符串）

**第19-24行：解析 token**
```javascript
if (userInfo) {
  try {
    const user = JSON.parse(userInfo);  // 字符串转对象
    token = user.token;  // 提取 token
  } catch (e) {
    console.error("解析用户信息失败:", e);
  }
}
```
- `JSON.parse()`：将 JSON 字符串转换为对象
- `try/catch`：捕获解析错误（如果数据格式不正确）

**第29-33行：设置请求头**
```javascript
config.headers = {
  ...config.headers,  // 展开运算符，保留原有请求头
  "Content-Type": "application/json;charset=UTF-8",
  token: token,  // 添加 token
};
```
- `...config.headers`：展开运算符，保留原有请求头
- `token: token`：将 token 添加到请求头，后端通过 `req.headers.token` 获取

**知识点：**
- **拦截器**：在请求发送前自动执行
- **展开运算符**：`...` 用于对象展开
- **JSON.parse()**：字符串转对象

#### 2.1.4 Axios 响应拦截器（Token 自动刷新）

**文件：** `src/request/axios.js`

```javascript
// 第51-81行：响应拦截器
request.interceptors.response.use(
  (res) => {
    // 1. 检查响应数据是否存在
    if (res && res.data) {
      // 2. Token 自动刷新逻辑
      if (res.data.token) {
        const userInfo = localStorage.getItem("leiyangUser");
        if (userInfo) {
          try {
            const user = JSON.parse(userInfo);
            user.token = res.data.token;  // 更新 token
            localStorage.setItem("leiyangUser", JSON.stringify(user));  // 保存新 token
          } catch (e) {
            console.error("更新 token 失败:", e);
          }
        }
      }
      return res.data;  // 返回响应数据
    }
    throw Error("请求数据失败");
  },
  (err) => {
    // 3. 错误处理
    if (err.response && err.response.data) {
      // 有响应体的错误也 resolve，前端能拿到 code/msg
      return Promise.resolve(err.response.data);
    }
    // 只有断网、超时等才 reject
    return Promise.reject(err);
  }
);
```

**逐行解释：**

**第54-67行：Token 刷新**
```javascript
if (res.data.token) {
  const userInfo = localStorage.getItem("leiyangUser");
  if (userInfo) {
    const user = JSON.parse(userInfo);
    user.token = res.data.token;  // 更新 token
    localStorage.setItem("leiyangUser", JSON.stringify(user));  // 保存
  }
}
```
- 如果响应中包含新的 token，自动更新 localStorage 中的 token
- 实现 token 的自动刷新，无需用户重新登录

**第68行：返回数据**
```javascript
return res.data;
```
- 统一返回 `res.data`，简化后续代码（不需要每次都写 `res.data`）

**第72-79行：错误处理**
```javascript
if (err.response && err.response.data) {
  return Promise.resolve(err.response.data);  // 有响应体的错误也 resolve
}
return Promise.reject(err);  // 只有断网、超时才 reject
```
- 区分业务错误和网络错误
- 业务错误（如 401、403）返回错误数据，网络错误直接 reject

**知识点：**
- **响应拦截器**：在响应返回后自动执行
- **Token 刷新**：自动更新过期的 token
- **错误处理**：区分业务错误和网络错误

#### 2.1.5 路由守卫

**关键代码位置：** `src/router/index.js`

```javascript
// 第163-185行：路由守卫
router.beforeEach((to, from, next) => {
  // 1. 检查用户是否已登录
  const isAuthenticated = localStorage.getItem("leiyangUser");

  // 2. 需要登录但未登录的情况

    (to.path === "/home/login" || to.path === "/home/register") &&
    isAuthenticated
  ) {
    next("/home");  // 跳转到首页
    return;
  }

  // 4. 其他情况正常放行
  next();
});
```

**逐行解释：**


### 2.4 数据筛选模块

#### 2.4.1 树形结构筛选

**关键代码位置：** `src/components/dataService/condition/ConditionBox.vue`

**三层筛选结构：**
1. **资源树**：能源类型（如：发电侧/风力发电/低空风电/陆上风电）
2. **数据类型树**：数据指标（如：潜力数据/容量因子）
3. **子节点树**：空间/时间分辨率（如：2.5MW/10km/年）

**实现原理：**
- 使用 Element Plus 的 `el-tree` 组件
- 通过 `check-strictly` 实现父子节点独立选择
- 选择叶子节点后，组合路径生成数据查询路径

```javascript
const handleResourceCheckChange = (data, checked) => {
  if (checked) {
```

## 3. 技术难点与解决方案

### 3.1 2D/3D地图无缝切换

**难点：**
- 两个不同的地图引擎，需要统一数据源和交互逻辑
- 切换时需要保持当前视图状态（中心点、缩放级别）

**解决方案：**
- 使用 `v-show` 控制显示/隐藏，而不是 `v-if`（避免重复初始化）
- 通过 props 统一传递地图路径参数
- 使用 `watch` 监听参数变化，动态更新图层

```javascript

  dimensionFlag.value = dimensionFlag.value === 2 ? 3 : 2;

<Map3D v-show="dimensionFlag == 3" :qgsMapPath="qgsMapPath" :tifMapPath="tifMapPath" />
```

### 3.2 WMS服务Token认证

**难点：**
- WMS服务需要Token认证，但标准WMS协议不支持自定义Header

**解决方案：**
- 使用 `tileLoadFunction` 自定义瓦片加载函数
- 在 fetch 请求中添加 Token Header

```javascript
tileLoadFunction: function (imageTile, src) {
  fetch(src, {
    headers: { Token: token }
  })
    .then(response => response.blob())
    .then(blob => {
      const objectUrl = URL.createObjectURL(blob);
      imageTile.getImage().src = objectUrl;
    });
}
```

**难点：**
- 切换语言时需要保持用户选择的数据结果
- 不同语言的数据结构可能不同

**难点：**

**Q14: Axios 拦截器是如何配置的？**

**答案：**
1. **请求拦截器**：自动从 localStorage 获取 token，添加到请求头
2. **响应拦截器**：统一处理响应数据，支持 token 自动刷新

**关键代码：**
```javascript
// 请求拦截器
request.interceptors.request.use((config) => {
  const userInfo = localStorage.getItem("leiyangUser");
  let token = "";
  if (userInfo) {
    token = JSON.parse(userInfo).token;
  }
  config.headers = {
    ...config.headers,
    "Content-Type": "application/json;charset=UTF-8",
    token: token,
  };
  return config;
});

// 响应拦截器
request.interceptors.response.use((res) => {
  if (res && res.data) {
    // 支持 token 自动刷新
    if (res.data.token) {
      const user = JSON.parse(localStorage.getItem("leiyangUser"));
      user.token = res.data.token;
      localStorage.setItem("leiyangUser", JSON.stringify(user));
    }
    return res.data;
  }
  throw Error("请求数据失败");
});
```

```javascript
// ChartBox.vue
const handlerChange = (value) => {
  selectedAreaValue.value = value;
  // 更新图表
  updateChart();
};

const updateChart = async () => {
  const res = await getLinedata({
    map: selectMapPath,
    timescale: timeScale,
    timespan: timeSpan,
    level: level,
    places: selectedPlaces,  // 选中的区域
    language: locale.value,
  });
  
  chart.setOption({
    xAxis: { data: res.xAxis },
    series: [{ data: res.series }],
  });
};
```

**关键点：**
- 支持多区域选择（级联选择器的 `multiple: true`）
- 选择变化时自动更新图表
- 支持多时间维度筛选
