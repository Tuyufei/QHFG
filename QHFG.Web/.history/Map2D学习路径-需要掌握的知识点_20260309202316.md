### 🔴 必须掌握（核心）

#### 1. **OpenLayers 基础概念** ⭐⭐⭐⭐⭐

**必须理解：**
- **Map（地图）**：地图容器，所有图层的载体
- **View（视图）**：控制地图的显示状态（中心点、缩放级别、投影）
- **Layer（图层）**：数据的展示层，负责渲染
- **Source（数据源）**：数据的提供者，负责获取数据
- **坐标系**：EPSG:4326（地理坐标系）vs EPSG:3857（Web墨卡托）

**代码位置：**
```javascript
// 第39-40行：导入
import Map from "ol/Map.js";
import View from "ol/View.js";

// 第684-693行：创建地图
map.value = new Map({
  target: "mapView",
  layers: [...],
  view: new View({ ... }),
});
```

**学习重点：**
- Source → Layer → Map 的关系
- 图层叠加顺序（数组顺序决定）
- 坐标系统的作用和区别

### 2. WMS图层创建（第72-130行）

```javascript
const createQgjZoomLayer1 = () => {
  const customTileGrid = new TileGrid({
    tileSize: 1024,
    origin: [-180, 90],
    resolutions: [0.703125, 0.3515625, 0.17578125],
  });
  
  const qgjMapSource = new TileWMS({
    url: `${baseURL}/map/getmap`,
    params: {
      SERVICE: "WMS",
      Map: props.qgsMapPath,
      LAYERS: props.tifMapPath,
    },
    tileLoadFunction: function (imageTile, src) {
      fetch(src, {
        headers: { Token: `${token}` },
      })
        .then(response => response.blob())
        .then(blob => {
          imageTile.getImage().src = URL.createObjectURL(blob);
        });
    },
  });
  
  return new Tile({
    source: qgjMapSource,
  });
};
```

## 📝 四、面试重点问题

### Q1: 要理解Map2D.vue，需要掌握哪些知识点？

**答案：**
"要理解Map2D.vue，需要掌握以下几个方面的知识：

1. **OpenLayers基础**：Map、View、Layer、Source的概念和关系
2. **WMS服务**：WMS协议的基本原理和Token认证的实现
3. **Vue 3 Composition API**：ref、watch、生命周期钩子
4. **坐标系统**：EPSG:4326坐标系和坐标标准化
5. **地图交互**：点击事件、移动事件的处理
6. **性能优化**：双分辨率策略、防抖处理

其中，**OpenLayers基础**和**WMS服务**是最核心的，因为这是地图组件的底层技术。"

---

### Q2: Source和Layer的区别是什么？

**答案：**
"Source（数据源）和Layer（图层）是OpenLayers中的两个核心概念：

- **Source**：负责获取数据，如XYZ、TileWMS、VectorSource
- **Layer**：负责渲染数据，如Tile、VectorLayer
- **关系**：一个Layer对应一个Source，Layer将Source的数据渲染到地图上

在Map2D.vue中，比如：
- `tiandituMapSource`是XYZ数据源，负责获取天地图瓦片
- `tiandiMapLayer`是Tile图层，负责将瓦片渲染到地图上"

---

### Q3: 如何实现WMS服务的Token认证？

**答案：**
"标准WMS协议不支持自定义Header，无法直接传递Token。我使用`tileLoadFunction`自定义瓦片加载函数：

1. 使用fetch替代默认的img.src加载
2. 在fetch请求中添加Token Header
3. 将响应转换为Blob
4. 创建ObjectURL赋值给瓦片图片

这样就实现了WMS服务的Token认证，同时兼容了标准WMS协议。"
