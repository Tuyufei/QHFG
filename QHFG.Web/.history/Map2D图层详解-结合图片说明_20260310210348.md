## 📋 一、Map2D.vue 中的图层列表

根据代码分析，Map2D.vue中共有**7个图层**（按zindex从低到高）：

1. **tiandiMapLayer** - 天地图矢量底图（zindex: 1）
2. **qgjZoomLayer1** - WMS数据图层（zindex: 2）
3. **tiandituBoundaryLayer** - 全球境界图层（zindex: 3）
4. **markerLayer** - 标记点图层（zindex: 5）
5. **highLightLayer** - 地图边界高亮图层（zindex: 7）
6. **countryPointLayer** - 国家点图层（zindex: 10）
7. **tiandituMessageLayer** - 天地图矢量注记图层（zindex: 100）

## 🗺️ 二、每个图层详解（结合图片说明）

### 1. tiandiMapLayer - 天地图矢量底图 ⭐⭐⭐⭐⭐

**代码位置：** 第60-67行

```javascript
const tiandituMapSource = new XYZ({
  url: "http://t0.tianditu.com/DataServer?T=vec_w&tk=xxx&x={x}&y={y}&l={z}",

const tiandiMapLayer = new Tile({
```

**图层类型：** Tile Layer（瓦片图层）

**在图片中的位置：**
- **最底层**，是整个地图的基础
- 显示**陆地轮廓**和**海洋区域**
- 图片中可以看到：
  - 各大洲的轮廓（非洲、欧洲、亚洲、澳大利亚等）
  - 海洋的浅蓝色区域
  - 基本的地理边界

**特点：**
- zindex: 1（最底层）
- 所有其他图层都叠加在这个底图之上
- 提供基本的地理信息

### 2. qgjZoomLayer1 - WMS数据图层 ⭐⭐⭐⭐⭐

**代码位置：** 第72-130行

**图层类型：** Tile Layer（WMS瓦片图层）

**在图片中的位置：**
- **数据覆盖层**，显示在底图之上
- 图片中可以看到：
  - **紫色到绿色的颜色渐变覆盖层**
  - 表示**容量因子（Capacity Factor）**的数值分布
  - 紫色区域：容量因子较低（接近0）
  - 绿色/黄色区域：容量因子较高（接近0.901）
  - 覆盖在各大洲上，显示风力发电潜力数据

**特点：**
- zindex: 2（在底图之上）
- 这是**核心数据图层**，显示用户选择的数据（如"陆上风电 容量因子"）
- 透明度可能设置为0.8左右，可以看到底图
- 根据筛选条件动态加载（qgsMapPath和tifMapPath）

**图片对应：**
- 图片中**紫色到绿色的渐变覆盖层**就是这个图层
- 图例中的颜色梯度（0到0.901）对应这个图层的数据值

## 📝 五、图层加载逻辑

### 根据语言返回不同的图层数组

```javascript
// 第636-654行
function getBaseLayersByLocale(localeVal) {
  if (localeVal === "english") {
    // 英文：底图、边界、marker、国家点
    return [
      tiandiMapLayer,        // 底图
      tiandituBoundaryLayer, // 境界
      markerLayer,           // 标记点
      countryPointLayer,     // 国家点
    ];
  } else {
    // 中文：底图、中文注记、边界、marker
    return [
      tiandiMapLayer,        // 底图
      tiandituMessageLayer,  // 中文注记
      tiandituBoundaryLayer, // 境界
      markerLayer,           // 标记点
    ];
  }
}
```

**图片对应：**
- 图片显示的是**中文环境**，所以包含：
  - tiandiMapLayer（底图）
  - tiandituMessageLayer（中文注记）
  - tiandituBoundaryLayer（境界）
  - markerLayer（标记点，未点击时不显示）

### 动态添加WMS数据图层

```javascript
// 第657-681行
watch(
  () => [props.qgsMapPath, props.tifMapPath],
  ([newQgs, newTif]) => {
    if (map.value && newQgs && newTif) {
      qgjZoomLayer1.value = createQgjZoomLayer1();
      const layers = getBaseLayersByLocale(locale.value);
      layers.splice(1, 0, qgjZoomLayer1.value);  // 插入WMS数据图层
      layers.push(highLightLayer);  // 添加高亮图层
      map.value.setLayers(layers);
    }
  }
);
```

**图片对应：**
- 图片中显示了WMS数据图层（紫色到绿色的覆盖层）
- 说明用户已经选择了数据（"陆上风电 容量因子"）
