## 绘制流程

### 1. 创建容器（DOM元素）

```html
<!-- Map2D.vue template -->
<template>
  <div class="map-container">
    <div class="mapView" id="mapView"></div>  <!-- 地图容器 -->
  </div>
</template>
```

**步骤**：在模板中定义地图容器 `<div id="mapView">`

### 2. 创建数据源（Source）

#### 2.1 天地图底图数据源
```javascript
// 天地图矢量底图数据源
const tiandituMapSource = new XYZ({
  url: "http://t0.tianditu.com/DataServer?T=vec_w&tk=...&x={x}&y={y}&l={z}",
});
```

#### 2.2 天地图注记数据源
```javascript
// 中文注记数据源
const tiandituMessageSource = new XYZ({
  url: "http://t0.tianditu.com/DataServer?T=cia_w&x={x}&y={y}&l={z}&tk=...",
  tilePixelRatio: 2,
  crossOrigin: "anonymous",
});
```

#### 2.3 全球境界数据源
```javascript
// 全球境界数据源（WMTS）
const tiandituBoundarySource = new XYZ({
  url: "http://t0.tianditu.gov.cn/ibo_w/wmts?...",
});
```

#### 2.4 WMS数据源（动态创建）
```javascript
// WMS栅格数据源（根据用户选择动态创建）
const qgjMapSource = new TileWMS({
  url: `${baseURL}/map/getmap`,
  params: {
    SERVICE: "WMS",
    VERSION: "1.1.0",
    REQUEST: "GetMap",
    Map: props.qgsMapPath,
    LAYERS: props.tifMapPath,
    FORMAT: "image/png",
    CRS: "EPSG:4326",
    language: locale.value,
  },
  tileGrid: customTileGrid,
  serverType: "geoserver",
  tileLoadFunction: function (imageTile, src) {
    // 自定义加载函数，添加Token认证
  },
});
```

#### 2.5 矢量数据源
```javascript
// 标记点矢量源
const markerSource = new VectorSource();

// 国家点矢量源（GeoJSON）
const countryPointSource = new VectorSource({
  url: "/map/国家点.json",
  format: new GeoJSON(),
});
```

### 3. 创建图层（Layer）

#### 3.1 底图图层
```javascript
const tiandiMapLayer = new Tile({
  zindex: 1,
  title: "矢量底图",
  source: tiandituMapSource,
});
```

#### 3.2 中文注记图层
```javascript
const tiandituMessageLayer = new Tile({
  zindex: 100,
  title: "矢量注记地图",
  source: tiandituMessageSource,
  minZoom: 1,
  maxZoom: 18,
  preload: Infinity,
  updateWhileAnimating: true,
  updateWhileInteracting: true,
  renderMode: "vector",
  renderBuffer: 200,
});
```

#### 3.3 全球境界图层
```javascript
const tiandituBoundaryLayer = new Tile({
  zindex: 3,
  title: "全球境界",
  source: tiandituBoundarySource,
});
```

#### 3.4 WMS渲染图层（动态创建）
```javascript
const qgjZoomLayer1 = new Tile({
  zindex: 2,
  title: "渲染地图",
  source: qgjMapSource,
  minZoom: 0,
  maxZoom: 12,
});
```

#### 3.5 标记点图层
```javascript
const markerLayer = new VectorLayer({
  zindex: 5,
  source: markerSource,
  style: new Style({
    image: new Circle({
      radius: 6,
      fill: new Fill({ color: "red" }),
      stroke: new Stroke({ color: "white", width: 2 }),
    }),
  }),
});
```

#### 3.6 国家点图层
```javascript
const countryPointLayer = new VectorLayer({
  zIndex: 10,
  title: "国家点",
  visible: true,
  source: countryPointSource,
  style: function (feature) {
    return new Style({
      text: new Text({
        font: "normal 14px 微软雅黑",
        text: feature.get("NAME") || "",
        fill: new Fill({ color: "#222" }),
        stroke: new Stroke({ color: "#fff", width: 2 }),
        offsetY: -12,
      }),
    });
  },
});
```

#### 3.7 高亮图层（动态创建）
```javascript
const highLightLayer = new Tile({
  zindex: 7,
  title: "地图边界",
  source: highLightSource,
  minZoom: 0,
  maxZoom: 12,
});
```

### 4. 创建地图对象（Map）

```javascript
onMounted(() => {
  map.value = new Map({
    target: "mapView",                    // 指定DOM容器
    layers: getBaseLayersByLocale(locale.value),  // 初始图层数组
    view: new View({
      center: [116.46, 39.92],           // 初始中心点（北京）
      projection: "EPSG:4326",           // 地理坐标系
      zoom: 1,                           // 初始缩放级别
    }),
    controls: [],                         // 不显示默认控件
  });
});
```

### 5. 添加事件监听

```javascript
// 点击事件
map.value.on("click", handleMapClick);

// 视图变化事件

```

## 图层结构详解

### 图层顺序（从下到上，zindex 从小到大）

| zindex | 图层名称 | 类型 | 数据源 | 说明 |
|--------|---------|------|--------|------|
| **1** | 天地图矢量底图 | Tile | XYZ | 基础底图，始终显示 |
| **2** | WMS渲染图层 | Tile | TileWMS | 业务数据图层，动态创建 |
| **3** | 全球境界 | Tile | XYZ (WMTS) | 边界线图层 |
| **5** | 标记点图层 | VectorLayer | VectorSource | 用户点击标记点 |
| **7** | 高亮图层 | Tile | TileWMS | 区域高亮显示，动态创建 |
| **10** | 国家点图层 | VectorLayer | VectorSource (GeoJSON) | 仅英文环境显示 |
| **100** | 中文注记图层 | Tile | XYZ | 仅中文环境显示 |

### 图层分类

#### 静态图层（始终存在）
- **zindex: 1** - 天地图矢量底图
- **zindex: 3** - 全球境界
- **zindex: 5** - 标记点图层

#### 动态图层（根据条件创建）
- **zindex: 2** - WMS渲染图层（有数据时创建）
- **zindex: 7** - 高亮图层（有数据时创建）

#### 语言相关图层
- **zindex: 10** - 国家点图层（仅英文）
- **zindex: 100** - 中文注记图层（仅中文）

## 中英文图层区别

### 中文环境图层顺序

```javascript
// 中文：底图、中文注记、边界、marker
[
  tiandiMapLayer,          // zindex: 1  - 天地图矢量底图
  tiandituMessageLayer,   // zindex: 100 - 中文注记（城市名、地名等）
  tiandituBoundaryLayer,  // zindex: 3  - 全球境界
  markerLayer,            // zindex: 5  - 标记点图层
]
```

**特点**：
- ✅ 显示中文注记图层（城市名、地名等中文标签）
- ❌ 不显示国家点图层
- ✅ 注记内容为中文

### 英文环境图层顺序

```javascript
// 英文：底图、边界、marker、国家点（只显示地名标注，不显示蓝色圆点）
[
  tiandiMapLayer,          // zindex: 1  - 天地图矢量底图
  tiandituBoundaryLayer,  // zindex: 3  - 全球境界
  markerLayer,            // zindex: 5  - 标记点图层
  countryPointLayer,      // zindex: 10 - 国家点图层（英文地名标签）
]
```

**特点**：
- ❌ 不显示中文注记图层
- ✅ 显示国家点图层（只显示英文地名标签，不显示蓝色圆点）
- ✅ 注记内容为英文

### 有数据时的完整图层顺序

#### 中文环境（有数据）
```javascript
[
  tiandiMapLayer,          // zindex: 1  - 底图
  qgjZoomLayer1,          // zindex: 2  - WMS渲染图层（业务数据）
  tiandituMessageLayer,   // zindex: 100 - 中文注记
  tiandituBoundaryLayer,  // zindex: 3  - 全球境界
  markerLayer,            // zindex: 5  - 标记点
  highLightLayer,         // zindex: 7  - 高亮图层
]
```

#### 英文环境（有数据）
```javascript
[
  tiandiMapLayer,          // zindex: 1  - 底图
  qgjZoomLayer1,          // zindex: 2  - WMS渲染图层（业务数据）
  tiandituBoundaryLayer,  // zindex: 3  - 全球境界
  markerLayer,            // zindex: 5  - 标记点
  highLightLayer,         // zindex: 7  - 高亮图层
  countryPointLayer,      // zindex: 10 - 国家点（英文地名）
]
```

## 完整流程图

```
1. 组件挂载（onMounted）
   ↓
2. 创建地图容器（DOM: #mapView）
   ↓
3. 创建数据源（Source）
   ├─ 天地图底图数据源（XYZ）
   ├─ 中文注记数据源（XYZ）
   ├─ 全球境界数据源（XYZ/WMTS）
   ├─ 标记点矢量源（VectorSource）
   └─ 国家点矢量源（VectorSource + GeoJSON）
   ↓
4. 创建图层（Layer）
   ├─ 底图图层（zindex: 1）
   ├─ 中文注记图层（zindex: 100，仅中文）
   ├─ 全球境界图层（zindex: 3）
   ├─ 标记点图层（zindex: 5）
   └─ 国家点图层（zindex: 10，仅英文）
   ↓
5. 根据语言选择基础图层
   ├─ 中文：底图 + 中文注记 + 边界 + 标记点
   └─ 英文：底图 + 边界 + 标记点 + 国家点
   ↓
6. 创建地图对象（Map）
   ├─ 指定容器：target: "mapView"
   ├─ 设置图层：layers: getBaseLayersByLocale()
   └─ 配置视图：center, projection, zoom
   ↓
7. 监听数据变化（watch props）
   ├─ 有数据时：
   │  ├─ 创建WMS渲染图层（zindex: 2）
   │  ├─ 创建高亮图层（zindex: 7）
   │  └─ 插入到图层数组
   └─ 无数据时：
      └─ 移除动态图层
   ↓
8. 添加事件监听
   ├─ click 事件：handleMapClick
   └─ moveend 事件：handleViewChange
   ↓
9. 地图渲染完成
```

### 地图初始化

### 动态图层管理
```javascript
// Map2D.vue - watch props
watch(
  () => [props.qgsMapPath, props.tifMapPath],
  ([newQgs, newTif]) => {
    if (map.value && newQgs && newTif) {
      qgjZoomLayer1.value = createQgjZoomLayer1();
      const layers = getBaseLayersByLocale(locale.value);
      layers.splice(1, 0, qgjZoomLayer1.value);  // 插入WMS图层
      layers.push(highLightLayer);                // 添加高亮图层
      map.value.setLayers(layers);
    }
  }
);
```

## 总结

### 绘制流程总结
1. **容器** → 2. **数据源** → 3. **图层** → 4. **地图对象** → 5. **事件监听**

### 图层结构总结
- **7个图层**：底图、WMS渲染、境界、标记点、高亮、国家点、中文注记
- **zindex范围**：1 ~ 100
- **动态图层**：WMS渲染图层、高亮图层（根据数据动态创建）

### 中英文区别总结
- **中文**：显示中文注记图层，不显示国家点图层
- **英文**：显示国家点图层（英文地名），不显示中文注记图层
- **共同**：底图、境界、标记点图层都显示
